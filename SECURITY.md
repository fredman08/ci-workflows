# Security Policy

## Reporting a vulnerability

Please report vulnerabilities privately via GitHub's
[private vulnerability reporting](https://github.com/fredman08/ci-workflows/security/advisories/new).
Do not open a public issue for security problems.

This repo ships reusable GitHub Actions workflows and commit-guard hooks. Reports about
script injection, unpinned or compromised dependencies, or hook bypasses are in scope.

## Supported versions

Only the latest `v1` tag and `main` receive fixes.
